# Link Battle Arena — alpha 0.1

A browser-native, single-screen combat prototype in an isolated experimental branch of the Zelda3 repository. Open `index.html` locally in your browser to play.

## Playable now

- Player versus AI in a top-down arena
- Touch D-pad or WASD / arrow keys
- Sword: J/Space; Shield: K; Spin: L; Pause: P
- Three hearts, knockback, directional blocking, invulnerability, wall collision, victory and rematch
- No copyrighted graphics or ROM required

## Not yet implemented

Actual Zelda3 engine integration or exact SNES combat behavior; two human-controlled players; multiplayer networking; Zelda graphics/music. This is a standalone original-art mechanics prototype, **not** a modified Zelda ROM.

## Roadmap
